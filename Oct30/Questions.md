# October 30 - Lab Work (CPU Scheduling & Page Replacement)

## Questions

1. **First-Come, First-Served (FCFS) CPU Scheduling**
   Write a C program to implement the FCFS CPU scheduling algorithm to calculate waiting time and turnaround time for a given set of processes.

2. **Shortest Job First (SJF) CPU Scheduling**
   Write a C program to implement the non-preemptive SJF CPU scheduling algorithm to calculate average waiting time and turnaround time.

3. **Priority CPU Scheduling**
   Write a C program to implement the non-preemptive Priority CPU scheduling algorithm (lower priority number indicates higher priority) and compute waiting time and turnaround time.

4. **FIFO Page Replacement Algorithm**
   Write a C program to implement the FIFO page replacement algorithm and calculate the total number of page faults for a given reference string and frame capacity.

5. **LRU Page Replacement Algorithm**
   Write a C program to implement the Least Recently Used (LRU) page replacement algorithm and calculate the total number of page faults.
