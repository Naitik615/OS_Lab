# September 18 - Lab Work

## Questions

1. **Array Sum in Parent and Prime Check in Child using Pipe**
   Write a C program where the parent process calculates the sum of an integer array and sends the sum to the child process using an unnamed pipe (`pipe()`). The child process receives the sum and determines whether it is a prime number.

2. **File Creation in Parent and Reading in Child Process**
   Write a C program to create a file `input.txt` in the parent process, write your name, university roll number, and class into it, and then have the child process open and read the same file, displaying its contents to stdout.
