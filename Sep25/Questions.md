# September 25 - Lab Work

## Questions

1. **Child Open File**
   Write a C program to demonstrate opening and reading a file in the child process created via `fork()`.

2. **Even Numbers in File via Child Process**
   Write a C program where the child process writes even numbers from 2 to 20 into a file, and the parent process waits, opens the file, and displays the numbers.

3. **Zombie and Orphan Process Demonstration**
   Write a C program to demonstrate both zombie and orphan process behaviors using process delays (`sleep()`) and `fork()`.
